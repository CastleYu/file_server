## 1. 数据对象类

### VirtualDirectory

**描述**: 虚拟目录配置对象，将虚拟名称映射到真实文件系统路径，并配置独立权限。

**文件**: `ftp_app.py`

#### 类常量

| 常量 | 类型 | 说明 |
|------|------|------|
| `VALID_PERMS` | `set` | 有效的权限字符集合 `{'e','l','r','a','d','f','m','w','M'}` |
| `INVALID_NAME_CHARS` | `set` | 虚拟目录名称的非法字符 `{'/','\\',':','*','?','"','<','>','|'}` |

#### 实例字段

| 字段 | 类型 | 说明 |
|------|------|------|
| `virtual_name` | `str` | 虚拟目录名称（在 FTP 中显示的名称） |
| `real_path` | `str` | 真实的文件系统路径 |
| `perm` | `str` | 权限字符串 |

#### 构造方法

```python
def __init__(self, virtual_name: str, real_path: str, perm: str = "elr")
```

| 参数 | 说明 |
|------|------|
| `virtual_name` | 虚拟目录名称，留空则自动使用文件夹名 |
| `real_path` | 真实路径 |
| `perm` | 权限字符串，默认只读 `"elr"` |

#### 方法组：名称与显示

| 方法 | 返回类型 | 说明 |
|------|----------|------|
| `get_display_name()` | `str` | 获取显示名称；若 `virtual_name` 为空，返回真实路径的文件夹名 |

#### 方法组：验证

| 方法 | 返回类型 | 说明 |
|------|----------|------|
| `validate()` | `List[str]` | 验证配置，返回错误消息列表 |
| `is_valid()` | `bool` | 检查配置是否有效 |

#### 方法组：序列化

| 方法 | 返回类型 | 说明 |
|------|----------|------|
| `to_dict()` | `Dict[str, Any]` | 转换为字典 |
| `from_dict(data)` | `VirtualDirectory` | （类方法）从字典创建实例 |

#### 静态方法

| 方法 | 说明 |
|------|------|
| `_sanitize_perm(perm: str)` | 清理权限字符串，过滤无效字符 |

#### 类常量

#### 方法组：验证

#### 方法组：序列化

| 方法 | 返回类型 | 说明 |
|------|----------|------|
| `to_dict()` | `Dict[str, Any]` | 转换为字典 |

## 2. 虚拟文件系统

### VirtualFS

**描述**: 虚拟文件系统类，继承自 `pyftpdlib.filesystems.AbstractedFS`。实现虚拟路径到真实路径的映射，是整个虚拟目录功能的核心。

**文件**: `ftp_app.py`

**继承**: `AbstractedFS`

#### 实例字段

| 字段 | 类型 | 说明 |
|------|------|------|
| `virtual_mappings` | `Dict[str, VirtualDirectory]` | 虚拟目录映射表 `{虚拟名称: VirtualDirectory}` |
| `user_profile` | `Optional[UserProfile]` | 当前用户配置 |
| `_cmd_channel` | `FTPHandler` | FTP 命令通道引用 |

#### 构造方法

```python
def __init__(self, root, cmd_channel)
```

| 参数 | 说明 |
|------|------|
| `root` | 用户根目录 |
| `cmd_channel` | FTP 命令通道 |

#### 方法组：用户配置管理

| 方法 | 说明 |
|------|------|
| `set_user_profile(profile: UserProfile)` | 设置用户配置并加载虚拟目录映射 |
| `_try_load_user_profile()` | 尝试从 cmd_channel 懒加载用户配置 |
| `_ensure_user_profile_loaded()` | 确保用户配置已加载（内部方法） |

#### 方法组：路径转换（核心）

| 方法 | 返回类型 | 说明 |
|------|----------|------|
| `ftp2fs(ftppath: str)` | `str` | 将 FTP 虚拟路径转换为真实文件系统路径 |
| `fs2ftp(fspath: str)` | `str` | 将真实路径转换回 FTP 虚拟路径 |
| `_parse_virtual_path(path: str)` | `tuple` | 解析虚拟路径，返回 `(is_virtual, vdir_name, sub_path, vdir_obj)` |

#### 方法组：路径验证与安全

| 方法 | 返回类型 | 说明 |
|------|----------|------|
| `validpath(path: str)` | `bool` | 验证路径是否有效且在允许范围内 |
| `_is_safe_path(path: str)` | `bool` | 检测路径遍历攻击 |
| `_is_valid_real_path(path: str)` | `bool` | 检查真实路径是否属于有效区域 |
| `_resolve_virtual_in_root(path: str)` | `str` | 解析根目录下的虚拟目录路径到真实路径 |

#### 方法组：目录操作

| 方法 | 说明 |
|------|------|
| `listdir(path: str)` | 列出目录内容，根目录时包含虚拟目录 |
| `chdir(path: str)` | 切换目录，更新 `_cwd` |
| `mkdir(path: str)` | 创建目录 |
| `rmdir(path: str)` | 删除目录（禁止删除虚拟目录本身） |

#### 方法组：文件信息查询

| 方法 | 返回类型 | 说明 |
|------|----------|------|
| `isdir(path: str)` | `bool` | 检查是否是目录 |
| `isfile(path: str)` | `bool` | 检查是否是文件 |
| `islink(path: str)` | `bool` | 检查是否是符号链接 |
| `lexists(path: str)` | `bool` | 检查路径是否存在 |
| `stat(path: str)` | `os.stat_result` | 获取文件状态 |
| `lstat(path: str)` | `os.stat_result` | 获取文件状态（不跟随链接） |
| `getsize(path: str)` | `int` | 获取文件大小 |
| `getmtime(path: str)` | `float` | 获取修改时间 |
| `realpath(path: str)` | `str` | 获取真实路径 |

#### 方法组：文件操作

| 方法 | 说明 |
|------|------|
| `open(filename: str, mode: str)` | 打开文件，带权限检查 |
| `remove(path: str)` | 删除文件 |
| `rename(src: str, dst: str)` | 重命名（禁止重命名虚拟目录本身） |
| `chmod(path: str, mode: int)` | 修改权限 |
| `utime(path: str, timeval)` | 设置访问/修改时间 |

## 3. 权限管理器

**描述**: 支持虚拟目录权限的认证器，扩展 `DummyAuthorizer` 实现按目录级别的权限检查。

**文件**: `ftp_app.py`

**继承**: `pyftpdlib.authorizers.DummyAuthorizer`

#### 实例字段

| 字段 | 类型 | 说明 |
|------|------|------|
| `user_profiles` | `Dict[str, UserProfile]` | 用户配置缓存 |

#### 方法组：用户管理

| 方法 | 说明 |
|------|------|
| `add_user_profile(profile: UserProfile)` | 添加用户配置，自动创建不存在的目录 |
| `get_user_profile(username: str)` | 获取用户配置 |

#### 方法组：权限检查

| 方法 | 返回类型 | 说明 |
|------|----------|------|
| `has_perm(username, perm, path)` | `bool` | 检查指定路径的权限，根据路径确定使用根目录或虚拟目录权限 |

## 7. 服务器控制器

### BaseServerController

**描述**: 服务器控制器抽象基类，封装服务器配置和管理的业务逻辑，提供与UI框架无关的接口。通过回调函数机制通知UI更新，便于移植到其他UI框架。

**文件**: `server_base.py`

**类型**: 抽象基类

#### 实例字段

| 字段 | 类型 | 说明 |
|------|------|------|
| `context` | `BaseServerContext` | 服务器上下文对象 |
| `server_thread` | `Optional[BaseServerThread]` | 服务器线程实例 |
| `callbacks` | `Dict[str, List[Callable]]` | 回调函数字典 |

#### 构造方法

```python
def __init__(self, context: BaseServerContext)
```

| 参数 | 说明 |
|------|------|
| `context` | 服务器上下文对象 |

#### 回调机制

| 方法 | 返回类型 | 说明 |
|------|----------|------|
| `register_callback(event, callback)` | `None` | 注册回调函数 |
| `unregister_callback(event, callback)` | `None` | 取消注册回调函数 |
| `_emit_callback(event, *args, **kwargs)` | `None` | 触发指定事件的所有回调函数（内部方法） |

**支持的事件类型**:
- `on_status` - 状态消息回调: `(message: str) -> None`
- `on_error` - 错误消息回调: `(message: str) -> None`
- `on_started` - 服务器启动回调: `() -> None`
- `on_stopped` - 服务器停止回调: `() -> None`

#### 抽象方法（子类必须实现）

| 方法 | 返回类型 | 说明 |
|------|----------|------|
| `create_server_thread()` | `BaseServerThread` | 创建服务器线程实例 |

#### 方法组：服务器控制

| 方法 | 返回类型 | 说明 |
|------|----------|------|
| `start_server(port)` | `Tuple[bool, Optional[str]]` | 启动服务器，返回 `(成功标志, 错误消息)` |
| `stop_server()` | `bool` | 停止服务器 |
| `is_server_running()` | `bool` | 检查服务器是否正在运行 |
| `get_server_port()` | `int` | 获取当前配置的服务器端口 |
| `set_server_port(port)` | `Tuple[bool, Optional[str]]` | 设置服务器端口 |
| `get_server_host()` | `str` | 获取当前配置的服务器监听地址 |
| `set_server_host(host)` | `Tuple[bool, Optional[str]]` | 设置服务器监听地址 |

#### 方法组：配置管理

| 方法 | 返回类型 | 说明 |
|------|----------|------|
| `save_config()` | `bool` | 保存配置到磁盘 |
| `reload_config()` | `bool` | 从磁盘重新加载配置 |
| `cleanup()` | `None` | 清理资源（程序退出时调用） |

#### 内部方法

| 方法 | 说明 |
|------|------|
| `_connect_thread_signals(thread)` | 连接服务器线程的信号到回调函数，将 PyQt 信号转换为回调机制 |

## 架构说明

### 分层架构

```
┌─────────────────────────────────────┐
│         UI 层 (MainWindow)          │  PyQt6 GUI 界面
├─────────────────────────────────────┤
│    控制器层 (FtpServerController)   │  业务逻辑封装，UI框架无关
├─────────────────────────────────────┤
│    服务层 (FtpServerThread)         │  服务器运行逻辑
├─────────────────────────────────────┤
│    数据层 (FtpServerContext)        │  配置和用户数据
└─────────────────────────────────────┘
```

### 控制器模式的优势

1. **UI 框架无关**: 控制器使用回调机制而非 PyQt 信号，可轻松移植到其他 UI 框架
2. **业务逻辑集中**: 所有服务器管理逻辑集中在控制器中，便于维护和测试
3. **清晰的接口**: 控制器提供清晰的 API，UI 层只需调用方法并注册回调
4. **可扩展性**: 其他类型的服务器可以继承 `BaseServerController` 实现自己的控制器
