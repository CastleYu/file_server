# FTP 服务器管理应用 - 简要介绍

## 概述

本应用是一个基于 PyQt6 的 FTP 服务器管理工具，核心使用 `pyftpdlib` 库实现 FTP 协议。通过继承 `AbstractedFS` 类实现了**虚拟目录映射**功能，支持单用户访问多个独立配置权限的文件夹。

## 核心特性

### 1. 虚拟目录系统
- 每个用户拥有一个**根目录**（登录后的默认目录）
- 可配置多个**虚拟目录**，在 FTP 客户端中显示为根目录下的子目录
- 每个虚拟目录映射到真实文件系统路径，并拥有独立的权限配置
- 虚拟目录名称可自定义，留空则自动使用真实路径的文件夹名

### 2. 细粒度权限控制
支持 pyftpdlib 标准权限字符：
| 字符 | 权限 | 说明 |
|------|------|------|
| `e` | 切换目录 | 允许 CWD 进入目录 |
| `l` | 列表 | 允许 LIST/NLST 列出目录内容 |
| `r` | 读取 | 允许下载文件 (RETR) |
| `a` | 追加 | 允许追加数据 (APPE) |
| `d` | 删除 | 允许删除文件/目录 (DELE/RMD) |
| `f` | 重命名 | 允许重命名 (RNFR/RNTO) |
| `m` | 创建目录 | 允许创建新目录 (MKD) |
| `w` | 写入 | 允许上传/覆盖 (STOR) |
| `M` | 修改权限 | 允许 SITE CHMOD |

### 3. GUI 管理界面
- PyQt6 实现的图形化管理界面
- 可视化用户管理（添加、编辑、删除）
- 可视化虚拟目录配置
- 服务器启动/停止控制
- 实时状态显示

### 4. 健壮性与安全性
- 路径遍历攻击防护
- 虚拟目录隔离（禁止删除/重命名虚拟目录本身）
- 优雅关闭机制（窗口关闭、Ctrl+C、异常崩溃时正确停止服务器）
- 配置持久化（JSON 格式保存用户配置）

## 快速开始

### 依赖安装
```bash
pip install PyQt6 pyftpdlib
```

### 运行应用
```bash
python ftp_app.py
```

### 基本使用流程
1. 启动应用后，点击"添加新用户"
2. 输入用户名和密码
3. 配置根目录路径和权限（默认只读）
4. 可选：添加虚拟目录并配置权限
5. 保存用户配置
6. 点击"启动服务器"
7. 使用 FTP 客户端连接（默认端口 2121）

## 环境变量

| 变量名 | 说明 | 默认值 |
|--------|------|--------|
| `FTP_LOG_LEVEL` | 日志级别（DEBUG/INFO/WARNING/ERROR） | `INFO` |

## 技术依赖

- **Python 3.10+**
- **PyQt6**: GUI 框架
- **pyftpdlib**: FTP 服务器库
